When a session is declared a pure think/plan session, behave so: **never** run tests, write code, or execute code in it (that happens in other sessions, to keep this chat flow clean and artifact-free); keep messages **short and terse** — a one-line question mid-discussion needs a short answer, not a recap; assume the user remembers prior context, so do not repeat or re-summarize what was discussed or re-explain already-explained things, unless asked or the user is clearly on the wrong track.

**Why:** keeps the planning chat a clean, dense exchange of ideas.
**How to apply:** ONLY when the user declares THIS session a think/plan session — do NOT generalize to other sessions.
