# Live Image Editor — test & demo page

A self-contained note for screenshots and manual testing. Each image uses one of the
synthetic samples in `images/` (generated by `generate-samples.sh`). The corner
labels **A** (top-left), **B** (top-right), **C** (bottom-left), **D** (bottom-right)
and the **TOP** marker make rotation/flip easy to read. **Should** = what a correct
render must show.

> Open `examples/` as a vault (or copy this note + `images/` into your test vault)
> with the plugin enabled. Hover an image to reveal the toolbar.
## Original

**Image 1 — Original (landscape, unchanged).** *Should:* A top-left, B top-right, C/D bottom, **TOP** at the top, sun top-right. Full column width, no overflow.

![](images/sample-landscape.png)

## Spacing (two images, no heading between)

**Images 1a & 1b — back-to-back images.** *Should:* exactly **6px** vertical gap between them (native parity), no extra space, no overlap.

![](images/sample-landscape.png){style="width: 300px;"}

## Rotate (quarter turns)

**Image 2 — 90° clockwise.** *Should:* **TOP** on the right (vertical, top→bottom), A top-right, B bottom-right, sun bottom-right. The box hugs the rotated image (no empty band top/bottom); width like a normal image.

![](images/sample-landscape.png){.lie-img style="--lie-rotate: 90deg;"}

**Image 3 — 180°.** *Should:* upside down — **TOP** at the bottom, A bottom-right, D top-left, sun bottom-left.

![](images/sample-landscape.png){.lie-img style="--lie-rotate: 180deg;"}

**Image 4 — 270° (90° counter-clockwise).** *Should:* **TOP** on the left (vertical), A bottom-left, B top-left, sun top-left. Box hugs the image like Image 2.

![](images/sample-landscape.png){.lie-img style="--lie-rotate: 270deg;"}

## Flip

**Image 5 — Flipped horizontally (portrait).** *Should:* **TOP** & arrow stay at the top, but left/right swapped: A top-**right**, B top-left; "PORTRAIT" reads mirrored.

![](images/sample-portrait.png){.lie-img style="--lie-flip-h: -1;"}
