# Live Image Editor — feature demo

A self-contained note for screenshots and manual testing. Every image below is one
of the synthetic samples in `images/` (generated by `generate-samples.sh`), so the
note can be committed and re-rendered anywhere. The `A B / C D` corner labels and
the **TOP** marker make rotation and flips easy to read at a glance.

> Open `examples/` as a vault (or copy this note + `images/` into your test vault)
> with the plugin enabled. Hover an image to reveal the toolbar.
