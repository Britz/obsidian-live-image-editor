# Live Image Editor — Example vault

A self-contained Obsidian vault that demonstrates **every** Live Image Editor feature on synthetic,
committable images (no third-party content). Open this folder as a vault with the plugin enabled,
then open any page below in **Live Preview** or **Reading view**, **hover** an image (or tap/click
it) to reveal the toolbar at the top of the image, and edit away — nothing is written to the image
file, only a small portable `{…}` block on the image's Markdown line.

The sample images carry corner labels — **A** top-left, **B** top-right, **C** bottom-left,
**D** bottom-right — and a **TOP** marker, so rotation and flip are easy to read. They live in
`images/` (3:2 landscape, 2:3 portrait, 1:1 square) and are regenerated by `generate-samples.sh`.

## The pages

- [[01 — Rotate & flip]] — quarter-turn rotation, free-rotation (in crop), horizontal / vertical flip.
- [[02 — Crop]] — the in-place crop editor: pan, zoom, rotate, aspect presets.
- [[03 — Size & presets]] — width resize, the size presets (icon / small / medium / large / original).
- [[04 — Filters]] — brightness, contrast, saturation, hue, blur, grayscale, sepia + named presets.
- [[05 — Layout, float & wrap]] — align left / right / center, text wrap around floats, inline icons.
- [[06 — Captions]] — alt-text captions rendered as Markdown below the image.
- [[07 — Classes & snippets]] — the bundled decoration classes (rounded, shadow, border, circle).

## Two things to enable first

- **Captions** are off by default → **Settings → Live Image Editor → Show image captions**.
- The **decoration snippets** ([[07 — Classes & snippets]]) ship opt-in → **Settings → Live Image
  Editor → Install example snippets** (this vault already has them installed and enabled).

> The blocks on these pages are written in the plugin's portable bare-key format
> (`{rotate=90 width=300}`, `{filter="sepia(0.8)"}`, …). With the plugin disabled the image still
> shows — the native-faithful keys (`align`, `width`) survive, the rest fall back to the original.

## What's in this vault

- `images/` — the synthetic samples: `sample-landscape.png` (3:2), `sample-portrait.png` (2:3),
  `sample-square.png` (1:1), and `tiny-24.png` (a 24 px icon, for the too-small-to-hover case).
  Regenerate them with `scripts/generate-samples.sh`.
- `.obsidian/snippets/` — the bundled decoration snippets (`live-image-editor-examples.css`) and a
  float helper (`float-images.css`), pre-installed and enabled so [[07 — Classes & snippets]] works
  out of the box.
